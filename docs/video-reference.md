# 参考视频拆解

参考视频：<https://www.bilibili.com/video/BV1Rpxb6gEVH>

视频标题是《Vibe知识大赏 | 为什么有些音乐，一听就是中国风或日本风？》，作者为“普雷尔王”，时长约 92 秒，B 站页面标记含 AI 生成内容。公开描述没有字幕文本，因此产品设计依据页面元数据和首帧/雪碧图的可见画面。

## 可复用的制作方法

- **先讲音乐规则，再生成声音**：用“五声音阶、宫商角徵羽、都节调式”等概念给风格建立可解释的骨架。
- **把声音转成画面**：用音高轨道、钢琴键盘、数字音阶和发光音符显示旋律如何移动。
- **用节拍驱动视觉**：每个音符的开始、结束、力度和节拍位置都进入同一个时间轴，让粒子、线条和字幕自动对齐。
- **用章节组织短视频**：引子、主题、展开、回望等段落对应画面状态和字幕，不把生成结果做成一条不可编辑的波形。
- **保持视觉识别度**：暗蓝黑底、细网格、荧光色轨迹和少量中文术语同时承担审美与解释功能。

## 平台映射

```text
场景/风格输入
    ↓
调式与音阶选择（五声 / 都节 / 自然小调）
    ↓
旋律、和声、配器、节奏生成
    ↓
统一 composition JSON
    ├─ 音乐：MIDI / MusicXML / 音频
    └─ 画面：音高轨迹 / 钢琴键 / 粒子 / 节拍闪光 / 字幕章节
    ↓
MP4 与可编辑工程
```

当前原型已经把前四步做成可运行的本地工作台，后续可以替换生成器和渲染器，而不用重做前端。
